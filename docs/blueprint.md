# **App Name**: Redpan E-Commerce

## Core Features:

- Dynamic Product Loading: Fetch and display products from Firestore in real-time.
- Add to Cart Functionality: Enable users to add products to a virtual cart and view confirmation.
- Cart Counter Update: Dynamically update the cart counter in the navigation bar when products are added.
- Responsive Design: Ensure the website is fully responsive and accessible on all devices (desktop, tablet, mobile).
- Firestore Integration: Connect the application to Firestore to read products from a database.
- Smooth Scrolling: Implement smooth scrolling for navigation links and the 'Shop Now' button.

## Style Guidelines:

- Primary color: Tech-focused red (#FF4500) to reflect hardware focus, inspired by the brand name.
- Background color: Dark gray (#333333) to create a modern and techy look.
- Accent color: A slightly lighter red (#FF6347) to highlight key elements.
- Headline font: 'Space Grotesk' sans-serif, with a computerized, techy, scientific feel. Body font: 'Inter' grotesque-style sans-serif.
- Use minimalist icons for navigation, cart, and social media links.
- Implement a clean, grid-based layout for the products section. Use a two-column layout for the About section.
- Add subtle hover effects to buttons and links for better user interaction.
